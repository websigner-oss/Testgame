الحل السريع:
-----------

1️⃣ اختبار بسيط أولاً:
   - افتح ملف: test-simple.html
   - اضغط "اختر صورة"
   - إذا عملت، المتصفح جيد ✅
   - إذا لم تعمل، جرب متصفح آخر (Chrome أو Firefox)

2️⃣ استخدام التطبيق الكامل:
   - افتح ملف: index.html
   - انتظر 10-30 ثانية (OpenCV.js يُحمّل)
   - ارفع صورة
   - اضغط "تحسين الجودة" (يعمل فوراً!)

3️⃣ للاستخدام على الموبايل:
   الطريقة الأفضل: استخدم GitHub Pages أو Netlify
   
   خطوات سريعة:
   أ) ارفع الملفات على GitHub
   ب) فعّل GitHub Pages
   ج) افتح الرابط على الموبايل
   
   أو استخدم خادم محلي:
   - على الكمبيوتر: python -m http.server 8000
   - على الموبايل: http://[عنوان-IP]:8000

4️⃣ نصائح مهمة:
   ✓ استخدم صور أقل من 5 MB
   ✓ انتظر تحميل OpenCV.js (أول مرة فقط)
   ✓ "تحسين الجودة" يعمل بدون OpenCV
   ✓ للميزات المتقدمة، انتظر OpenCV.js

5️⃣ رسائل الخطأ:
   - "يرجى تحميل صورة": ارفع صورة أولاً
   - "OpenCV لم يكتمل": انتظر أو جرب "تحسين الجودة"
   - "خطأ في قراءة الملف": جرب صورة أخرى
